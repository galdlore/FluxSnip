# FluxSnip プライバシーポリシー

最終更新日: 2026年10月12日

FluxSnip は、MIT ライセンスのもとで公開されているオープンソースのブラウザ拡張機能です。本プライバシーポリシーでは、FluxSnip における利用者のデータの取り扱い方針について説明します。

## 1. 基本方針

FluxSnip は、利用者のプライバシー保護を最優先に設計されています。いかなる個人情報や利用状況データも収集、外部送信、販売しません。すべての機能は利用者の端末内だけで動作します。

## 2. 取り扱うデータと保存場所

利用者が作成した定型文テンプレートや設定項目は、端末内の `chrome.storage.local` にのみ保存されます。

外部の専用サーバーは一切運用していません。ネットワーク経由でのデータ送信は行われません。

解析ツールや広告モジュール、遠隔エラー収集ツールなどの追跡プログラムも一切含みません。

## 3. 対象サービスのページ内容と本文データ

FluxSnip は、Gmail、Microsoft Teams、Google Chat の画面と連携して定型文の挿入機能を提供します。

ページ内の要素は、キーワードの検知や定型文の挿入、ピッカー画面の表示のために端末内でのみ読み取ります。

メッセージの本文や下書き、受信メールの内容、チャット履歴、連絡先情報を外部へ送信したり、記録したりすることはありません。

例外として、Gmail のメール作成画面で利用可能な差出人（From）アドレスの候補のみ、設定画面での選択肢表示に役立てるため、端末内の `chrome.storage.local` に保存します。この情報も外部には一切送信されません。

## 4. 利用する権限とその用途

FluxSnip が要求する権限は、定型文挿入に必要な最小限の範囲に限られます。

- storage: テンプレートや各種設定、差出人候補を端末内に保存するために利用します。
- unlimitedStorage: 画像を含むリッチテキストテンプレートを保存する際に、ブラウザ既定の容量上限を超えて保存できるようにするために利用します。
- 対象サイトへのアクセス権限（mail.google.com, chat.google.com, teams.microsoft.com, teams.cloud.microsoft）: 各サービスの入力欄でキーワード入力を検知し、定型文を挿入するプログラムを動作させるために利用します。

## 5. リモートコードの不使用と安全性

Chrome Web Store の方針および Manifest V3 のセキュリティ基準に従い、外部サーバーからの遠隔スクリプトやスタイルの読み込みは行いません。

実行に必要なすべてのコードとリソースは、拡張機能パッケージ内に同梱されています。
