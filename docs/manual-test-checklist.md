  - [ ] テーブル入りテンプレートを挿入した際、枠線付きの表として表示され、メール送信後も受信側で表構造が維持されること
  - [ ] 署名が設定されている場合、署名の手前に挿入され、署名が壊れず残ること

- [ ] **除外・ネイティブ保護**:

- [ ] **UI 言語互換性**:
  - [ ] Gmail の日本語 UI および英語 UI の両方で上記が同様に動作すること

## Playground（開発・動作確認用テストページ）
- [ ] **Playground 画面の起動**:
  - [ ] `chrome-extension://<拡張機能ID>/playground.html` を開き、3つのエディタ（Gmail, Teams, Google Chat）およびログエリアが表示されること
  - [ ] 「Seed Test Templates」をクリックし、テスト用テンプレート（;thx, ;table, ;teams, ;chat）が生成されること
- [ ] **キーワード Tab 展開（エディタ 1: Gmail Simulator）**:
  - [ ] エディタ内に `;thx` と入力して <kbd>Tab</kbd> キーを押すと、`田中様` や `自分` などの変数が展開された本文が挿入されること
  - [ ] エディタ内に `;table` と入力して <kbd>Tab</kbd> キーを押すと、枠線付きの日程テーブルが正しく挿入されること
- [ ] **自前 Paste ハンドラ経由の展開（エディタ 2: Teams Simulator）**:
  - [ ] エディタ内に `;teams` と入力して <kbd>Tab</kbd> キーを押すと、太字見出しや箇条書きを含む定型文が挿入され、ログに「Handled paste event」が出力されること
- [ ] **Chat テキスト展開（エディタ 3: Google Chat Simulator）**:
  - [ ] エディタ内に `;chat` と入力して <kbd>Tab</kbd> キーを押すと、Chat 用テキスト（`*太字*` など）が挿入されること
- [ ] **ピッカー起動 & 選択挿入**:
  - [ ] いずれかのエディタにフォーカスし、<kbd>Alt+J</kbd> を押すとキャレット位置直下にピッカーが開くこと
  - [ ] 検索ワードを入力して候補が絞り込まれ、<kbd>↑</kbd><kbd>↓</kbd> キーで選択移動し <kbd>Enter</kbd> で元のキャレット位置に挿入されること
  - [ ] <kbd>Esc</kbd> キーまたは外側クリックでピッカーが閉じ、元のエディタにフォーカスが戻ること
- [ ] **誤展開防止・ネイティブ動作保持**:
  - [ ] キーワードに一致しない文字列（例: `abc` や空白のみ）で <kbd>Tab</kbd> を押した際、展開されずブラウザ通常のフォーカス移動が起きること
  - [ ] 日本語 IME 変換中（未確定状態）で <kbd>Tab</kbd> を押しても展開が誤作動しないこと
