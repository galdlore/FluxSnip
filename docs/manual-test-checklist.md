## Options
- [ ] **タブ切替**: Gmail, Teams, Google Chat, 設定, バックアップのタブがスムーズに切り替わること
- [ ] **テンプレートCRUD (Gmail/Teams/Chat)**:
  - [ ] 「+ 新規作成」で新規フォームが開き、名前・キーワード・タグ・本文を入力して保存できること
  - [ ] 保存したテンプレートが左側の一覧に即座に反映され、キーワードバッジが表示されること
  - [ ] 一覧から選択して編集し、更新保存できること
  - [ ] 「複製」ボタンで `（コピー）` または ` (copy)` が付与され、キーワードが空の状態で新規複製されること
  - [ ] 「削除」ボタンで確認モーダルが表示され、削除できること
  - [ ] 未保存の変更がある状態で別テンプレやタブに切り替えようとした際、破棄確認モーダルが表示されること
  - [ ] `Ctrl+S` (Macは `⌘S`) で保存が実行できること
  - [ ] 検索ボックスで名前・キーワード・タグ・本文によるフィルタリングができること
- [ ] **バリデーション確認**:
  - [ ] 名前が空のときに赤字エラーが表示され保存が中止されること
  - [ ] 同一プラットフォーム内で重複するキーワードを入力したときにエラーが表示され、一覧に警告アイコンが表示されること
  - [ ] 不正なメールアドレス（GmailのTo/From等）を入力したときにエラーが表示されること
- [ ] **設定タブ**:
  - [ ] 「キーを記録」をクリックし、任意のキー（例: Alt+K）を押してショートカットが変更・保存されること
  - [ ] 「既定に戻す」で `Alt+J` に戻ること
  - [ ] 各プラットフォームの有効/無効トグルが正常に切り替わること
  - [ ] 検出済み差出人エイリアス一覧が表示され、削除できること
- [ ] **バックアップタブ**:
  - [ ] 「すべてエクスポート」で `fluxsnip-backup-*.json` がダウンロードできること
  - [ ] 「テンプレートをインポート」でファイルを読み込み、プレビューが表示されること
  - [ ] 「統合」および「完全置換」モードでインポートが正常に完了すること
