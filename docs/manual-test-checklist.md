## Options
- [ ] **タブ切替**: Gmail, Teams, Google Chat, 設定, バックアップのタブがスムーズに切り替わること
- [ ] **テンプレートCRUD (Gmail/Teams/Chat)**:
  - [ ] 「+ 新規作成」で新規フォームが開き、名前・キーワード・タグ・本文を入力して保存できること
  - [ ] 保存したテンプレートが左側の一覧に即座に反映され、キーワードバッジが表示されること
  - [ ] 一覧から選択して編集し、更新保存できること
  - [ ] 「複製」ボタンで `（コピー）` または ` (copy)` が付与され、キーワードが空の状態で新規複製されること
  - [ ] 「削除」ボタンで確認モーダルが表示され、削除できること
  - [ ] 未保存の変更がある状態で別テンプレやタブに切り替えようとした際、破棄確認モーダルが表示されること
  - [ ] `Ctrl+S` (Macは `⌘S`) で保存が実行できること
  - [ ] 検索ボックスで名前・キーワード・タグ・本文によるフィルタリングができること
- [ ] **バリデーション確認**:
  - [ ] 名前が空のときに赤字エラーが表示され保存が中止されること
  - [ ] 同一プラットフォーム内で重複するキーワードを入力したときにエラーが表示され、一覧に警告アイコンが表示されること
  - [ ] 不正なメールアドレス（GmailのTo/From等）を入力したときにエラーが表示されること
- [ ] **設定タブ**:
  - [ ] 「キーを記録」をクリックし、任意のキー（例: Alt+K）を押してショートカットが変更・保存されること
  - [ ] 「既定に戻す」で `Alt+J` に戻ること
  - [ ] 各プラットフォームの有効/無効トグルが正常に切り替わること
  - [ ] 検出済み差出人エイリアス一覧が表示され、削除できること
- [ ] **バックアップタブ**:
  - [ ] 「すべてエクスポート」で `fluxsnip-backup-*.json` がダウンロードできること
  - [ ] 「テンプレートをインポート」でファイルを読み込み、プレビューが表示されること
  - [ ] 「統合」および「完全置換」モードでインポートが正常に完了すること
- [ ] **本文リッチエディタ (Body Editor)**:
  - [ ] **モード切替**: 「ビジュアル」「HTML」「プレビュー」のタブ切替で内容が壊れず同一に保たれること
  - [ ] **書式ツールバー**: 太字(Ctrl+B)、斜体(Ctrl+I)、下線(Ctrl+U)、取消線、箇条書き、番号付き、引用、書式クリアが正常に動作すること
  - [ ] **リンク挿入**: ツールバーおよび Ctrl+K でリンクポップオーバーが開き、URL（http/https/mailto/tel）を指定して挿入・解除できること（不正なスキームは弾かれること）
  - [ ] **テーブル挿入 & コンテキストメニュー**:
    - [ ] テーブル挿入ボタンでグリッド（最大8×8）を選択し、枠線付きテーブルが挿入されること
    - [ ] テーブル内セルで右クリックし、行の上下挿入、列の左右挿入、行削除、列削除、テーブル削除が実行できること
  - [ ] **Excel / スプレッドシート貼り付け**:
    - [ ] Excel または Googleスプレッドシートの表セル範囲をコピーし、エディタにペーストした際、表構造（table/tr/td）およびセルの太字等の装飾が保持されること
  - [ ] **サニタイズ安全性**:
    - [ ] `<script>alert(1)</script>` や `<img src=x onerror=alert(1)>` を貼り付けまたは HTML タブに入力して切り替えた際、悪意あるタグや属性が完全に除去されること
  - [ ] **Chat プラットフォームの互換性挙動**:
    - [ ] Google Chat 選択時、テーブル挿入ボタンが非表示になること
    - [ ] テーブルや見出しを含む HTML がある場合、上部に Chat 非対応警告バナーが表示されること
    - [ ] 「プレビュー」タブで HTML 表示と並んで Google Chat 記法（テキスト形式）のプレビューが確認できること
  - [ ] **容量カウンター**:
    - [ ] 入力に合わせてリアルタイムに `X.X KB / 64 KB` が更新され、上限超過時に赤字警告表示になること
