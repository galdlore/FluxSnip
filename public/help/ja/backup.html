バックアップ

定型文と設定はこの端末に残ります。別のパソコンへ移すときは JSON ファイルを使います。FluxSnip が自分でアップロードすることはありません。

書き出す

すべてエクスポート、または Gmail・Teams・Chat のどれかだけを書き出します。「すべて」のファイル名は fluxsnip-backup-YYYYMMDD-HHmm.json です。1 つのサービスだけを書き出すと、ファイル名にその名前が入ります（例: fluxsnip-backup-gmail-YYYYMMDD-HHmm.json）。そのファイルでは他のサービスは空です。設定（ピッカーのショートカットや言語など）が入るのは「すべてエクスポート」だけです。

読み込む

  1. FluxSnip の JSON ファイルを選びます。プレビューに件数と、スキップされる行の理由が出ます。
  2. モードを選びます。
    • 統合は、id が新しい定型文を追加します。同じ id があるときは、更新日時が新しい方を残します。別の定型文がすでに同じキーワードを使っている場合はスキップします。
    • 置換は、ファイルに含まれるサービスの定型文を消し、ファイルの内容に入れ替えます。その前に、いまの内容をバックアップとしてダウンロードします。そのダウンロードに失敗したときは、置換を中止します。
  3. ファイルに設定が入っていて、このブラウザでもそれを使うときは拡張機能の設定も取り込むにチェックします。ショートカットや言語などを残したいときはオフのままにします。
  4. 実行します。追加、更新、スキップの件数が表示されます。

Google ドライブで別のパソコンへ渡す

  1. このパソコンで書き出し、JSON ファイルをパソコン版 Google ドライブのフォルダに保存します。拡張機能の中からアップロードするのではありません。
  2. もう一方のパソコンでファイルの同期を待ち、FluxSnip の設定画面から読み込みます。
  3. そのパソコンにしか無い定型文を消さず、新しい編集だけ取り込みたいときは統合を使います。

自動では同期しません。https: で始まる画像は、メッセージを表示するときにそのアドレスから読み込まれます。Gmail の「Gemini へ自動送信」をオンにしていると、Gemini 欄で展開したときにそのプロンプトが Google に送られます。
