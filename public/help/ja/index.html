概要

FluxSnip は、自分で書いた定型文を Gmail、Microsoft Teams、Google Chat に挿入します。

設定画面を開く

Chrome の FluxSnip アイコンをクリックします。定型文、設定、バックアップはこの画面にあります。右上のヘルプは、いま開いているタブの使い方を表示します。

定型文を挿入する

  1. メッセージ欄にキーワードを入力して Tab を押します。キーワードが一致したときだけ Tab を横取りします。一致しなければ、通常どおりフォーカスが移動します。IME で変換中の Tab は横取りしません。
  2. またはピッカーのショートカット（初期値は Alt+J）を押し、検索して Enter で挿入します。↑ と ↓ で選択を移動し、Esc で閉じます。

キーワードは大文字と小文字を区別します。1〜32 文字で、使える文字は英数字と _ - ; : . ! / @ # です。;thx のように先頭に ; を付けると、普通の単語とぶつかりにくくなります。

定型文はサービスごとに別です

Gmail タブに保存した定型文は、Teams や Chat では出ません。使うサービスのタブで作成してください。

  • Gmail — 本文、To/Cc/Bcc、件名、差出人、任意の Gemini プロンプト
  • Teams — メッセージ本文（表を含む）
  • Google Chat — Chat の書式に変換した本文
  • 設定 — 言語、ショートカット、有効・無効
  • バックアップ — 書き出しと読み込み

定型文の編集

  • + 新規作成は下書きです。保存するまで一覧には入りません。
  • 保存ボタン、または Ctrl+S（macOS は ⌘+S）で保存します。
  • 本文はビジュアル、HTML、プレビューを切り替えられます。Excel や Word から表を貼り付けられます。
  • 保存時に、スクリプトなどの危険な記述は取り除かれます。
  • 未保存の編集があるときに別の定型文やタブへ移ると、破棄の確認が出ます。
  • 複製は名前にコピーである印を付け、キーワードを空にします。新しいキーワードを付けて保存してください。
  • 同じキーワードの定型文が複数あると、一覧に警告が出ます。Tab で展開されるのは、更新日時が新しい方です。

言語

設定で「ブラウザに合わせる」「English」「日本語」を選びます。選んだ値はこの端末に保存され、設定画面、Gmail・Teams・Chat 上のメッセージ、このヘルプに使われます。「ブラウザに合わせる」は Chrome の言語に従います。Chrome の言語が日本語以外のときは、ヘルプは英語で開きます。

このページは、OS のライトモード／ダークモードに従います。定型文はこのブラウザの中だけに保存されます。
