Gmail

Create templates for mail.google.com and insert them in a compose window.

Shared editing steps (save, duplicate, search, the visual editor) are on the overview.

Insert

Focus the message body, the subject, or a recipient field. Type the keyword and press Tab, or open the picker (default Alt+J) and press Enter. The body is inserted at the caret, so a signature or quoted thread below it stays in place.

In Gmail, Ctrl+Z just after an expansion restores the keyword, and Ctrl+Y redoes it.

Header fields

Leave a field blank when the template should not change it.

FieldWhat it does
FromSelects a sender alias. It works only for an address already added in Gmail’s “Send mail as” settings.
To, Cc, BccOne address per line or separated by commas. Replace clears that field first. Append adds addresses.
SubjectReplace overwrites the subject. If empty writes it only when the subject is blank.

To, Cc, Bcc, From, and subject are recognized when Gmail’s own display language is Japanese or English. In another Gmail language the body can still expand, and a toast warns you if a header field could not be set.

Gemini prompt

Gemini Prompt (Alt+H) is text placed in Gmail’s Gemini box. {{cursor}} marks where the caret should land. Automatically submit when expanding in Gemini prompt sends that prompt to Gemini as soon as you expand the template there. Leave it off to edit the prompt before you run it. With it on, the prompt is sent to Google without an extra click.

Variables

Variables are filled in when you insert. An unknown name such as {{nickname}} is left as written. A known variable with no value becomes empty.

VariableResult
{{date}}Today as YYYY/MM/DD
{{date:YYYY年M月D日}}Your own date pattern. Tokens: YYYY MM DD M D HH mm ddd dddd
{{time}}Current time as HH:mm
{{weekday}}Short weekday in the active language
{{to.name}} {{to.firstName}} {{to.lastName}} {{to.email}}The first To recipient. “山田 太郎” splits into surname 山田 and given name 太郎. “John Smith” splits into John and Smith.
{{from.name}} {{from.email}}The selected From
{{cursor}}Caret position after expansion, in the Gmail body and the Gemini prompt
