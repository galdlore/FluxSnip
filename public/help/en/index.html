Overview

FluxSnip inserts templates you write into Gmail, Microsoft Teams, and Google Chat.

Open the options page

Click the FluxSnip icon in Chrome. Templates, settings, and backup all live on this page. The Help button opens the guide for the tab you are on.

Insert a template

  1. Type the template’s keyword in the message box and press Tab. Tab is taken over only when that keyword matches. If it does not match, Tab moves focus as usual. Tab does nothing special while an IME is converting text.
  2. Or press the picker shortcut (default Alt+J), type to search, and press Enter. ↑ and ↓ move the highlight. Esc closes the picker.

Keywords are case-sensitive, 1–32 characters, using letters, digits, and _ - ; : . ! / @ #. A leading ; such as ;thx is a good way to avoid ordinary words.

Templates are separate for each service

A template saved on the Gmail tab is not offered in Teams or Chat. Create it on the tab for the service where you want to use it.

  • Gmail — body, To/Cc/Bcc, subject, From, and an optional Gemini prompt
  • Teams — message body, including tables
  • Google Chat — message body, converted to Chat’s formatting
  • Settings — language, shortcut, and switches
  • Backup — export and import

Editing a template

  • + New Template starts a draft. It is not stored until you save.
  • Save with the button or Ctrl+S (⌘+S on macOS).
  • The body editor has Visual, HTML, and Preview. You can paste tables from Excel or Word.
  • Scripts and other unsafe markup are removed when you save.
  • Switching templates or tabs with unsaved edits asks you to confirm.
  • Duplicate copies the template, adds a copy marker to the name, and clears the keyword so you can set a new one.
  • If two templates share a keyword, the list shows a warning. The newest one is the one Tab expands.

Language

On Settings, choose Match browser, English, or 日本語. That choice is saved on this device and used for the options page, messages inside Gmail, Teams, and Chat, and these Help pages. Match browser follows Chrome’s language. If Chrome is set to a language other than Japanese, Help opens in English.

This page follows your system’s light or dark appearance. Templates stay in this browser.
