Backup

Templates and settings stay on this device. A JSON file is how you copy them to another computer. FluxSnip does not upload them.

Export

Choose Export All, or export only Gmail, Teams, or Chat. Export All is named fluxsnip-backup-YYYYMMDD-HHmm.json. A single-service file includes that service’s name, such as fluxsnip-backup-gmail-YYYYMMDD-HHmm.json, and leaves the other services empty. Only Export All includes settings, such as the picker shortcut and language.

Import

  1. Choose a FluxSnip JSON file. A preview lists how many templates it contains and any rows that will be skipped.
  2. Pick a mode.
    • Merge adds templates whose id is new. When the id already exists, the copy with the newer update time is kept. A template whose keyword is already used by a different template is skipped.
    • Replace deletes the current templates for the services in the file and writes the file’s templates instead. FluxSnip first downloads a backup of what you have now. If that download fails, the replace is cancelled.
  3. Check Also import settings when the file contains settings and you want this browser to use them. Leave it off to keep the shortcut, language, and other settings you already have.
  4. Run the import. The result shows how many templates were added, updated, or skipped.

Copying to another computer with Google Drive

  1. Export on this computer and save the JSON file into your Google Drive folder (the desktop Drive folder, not an upload inside the extension).
  2. On the other computer, wait until that file has synced, open FluxSnip options, and import it.
  3. Use Merge when you want to fold in newer edits without wiping templates that exist only on that computer.

There is no automatic sync. Images whose address starts with https: are loaded from that address when a message is shown. With Gmail’s “automatically submit Gemini” option on, that prompt is sent to Google when you expand the template in the Gemini box.
