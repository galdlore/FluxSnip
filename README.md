# FluxSnip

Keyword-triggered text and HTML template expansion for Gmail, Microsoft Teams (PWA), and Google Chat (PWA).

## Features
- **Keyword + Tab expansion**: Instant snippet insertion upon typing a shortcut and pressing Tab.
- **Search picker popup**: Quick template search and insertion via shortcut.
- **Gmail integration**: Replace To/Cc/Bcc recipients, set custom From aliases, and set subject lines.
- **Teams & Google Chat**: Rich HTML and formatted text insertion without polluting clipboard.
- **Zero runtime dependencies**: Pure native code for high performance and privacy.
- **Local storage**: All templates and settings are stored locally in your browser.

## Development

```bash
# Install dependencies
npm install

# Type checking
npm run compile

# Unit tests
npm test

# Build extension
npm run build

# Start dev mode
npm run dev

# Package extension zip
npm run zip
```
