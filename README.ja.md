# FluxSnip

[English](README.md) | [日本語](README.ja.md)

Gmail、Microsoft Teams（webかPWA版）、Google Chat（webかPWA版） 向けの定型文拡張機能です。短いキーワードを入力して Tab を押すか、検索ピッカーから選ぶと、カーソル位置に定型文が入ります。

定型文はこのブラウザの中だけに保存されます。拡張機能がそれを送信することはありません。

## インストール

開発中は、パッケージ化されていない拡張機能として読み込みます。

```bash
npm install
npm run build
```

1. `chrome://extensions` を開きます。
2. **デベロッパーモード**をオンにします。
3. **パッケージ化されていない拡張機能を読み込む**で `.output/chrome-mv3` フォルダを選びます。
4. FluxSnip のアイコンをクリックすると設定画面が開きます。

ビルドし直したあとは、同じカードの**再読み込み**を押してください。

## 使い方

定型文は、使うサービスのタブで作ります。Gmail に保存したものは Teams や Chat では出ません。

### キーワード + Tab

メッセージ欄にキーワードを入力して Tab を押します。キーワードが一致したときだけ Tab を横取りします。IME の変換中は何もしません。

キーワードは大文字と小文字を区別します。1〜32 文字で、使える文字は英数字と `_ - ; : . ! / @ #` です。`;thx` のように先頭へ `;` を付けると、普通の単語とぶつかりにくくなります。

### ピッカー

初期ショートカットは Alt+J です。検索し、矢印キーで選んで Enter で挿入します。Escape で閉じます。設定タブでショートカットを変えられます。Ctrl+Space など、IME が使っている組み合わせは避けてください。

### Gmail の項目

Gmail の定型文では、本文に加えて次を設定できます。

| 項目 | 動き |
| --- | --- |
| 差出人 | Gmail の「名前を付けて送信」に登録済みのエイリアスを選ぶ |
| To、Cc、Bcc | **置換**はその欄を消してから入れる。**追記**は足す。空ならその欄は変えない |
| 件名 | **置換**は上書きする。**空のときのみ**は件名が空のときだけ書く |
| Gemini 指示 | Gmail の Gemini 欄に入れる文章。`{{cursor}}` がカーソル位置。自動送信をオンにすると、その文章が Google に送られる |

宛先・件名・差出人は、Gmail 本体の表示言語が日本語または英語のときに認識します。それ以外でも本文の展開はできます。項目を設定できなかったときは警告が出ます。

### Gmail の推敲機能（Alt+H）へのプロンプト流し込み

Gmail の「文書作成サポート（Alt+H）」で開くプロンプト入力欄でも、キーワード + Tab やピッカー（Alt+J）による定型文展開がそのまま動作します。

「ビジネス敬語への書き換え」「英文校正の前提条件」「長文要約の制約」など、AIに与える指示文や役割定義（Skill）をあらかじめ定型文として登録しておくことで、長文のプロンプトを毎回手入力することなく瞬時に流し込めます。

また、Gmail 向けテンプレートの「Gemini 指示」欄に指示文を設定し、「自動で作成を実行する」をオンにしておけば、本文展開と同時に推敲プロンプトの送信まで自動で完了します。

### 変数

変数は挿入するときに置き換わります。未知の名前はそのまま残ります。

| 変数 | 結果 |
| --- | --- |
| `{{date}}` | 今日（YYYY/MM/DD） |
| `{{date:YYYY年M月D日}}` | 自分で指定した形。トークンは `YYYY` `MM` `DD` `M` `D` `HH` `mm` `ddd` `dddd` |
| `{{time}}` | 現在時刻（HH:mm） |
| `{{weekday}}` | 短い曜日 |
| `{{to.name}}` `{{to.firstName}}` `{{to.lastName}}` `{{to.email}}` | 最初の To（Gmail） |
| `{{from.name}}` `{{from.email}}` | 選択中の差出人（Gmail） |
| `{{cursor}}` | 展開後のカーソル。Gmail 本文と Gemini 指示で有効 |

### Teams と Google Chat

Teams は、会社テナントの `teams.microsoft.com` と `teams.cloud.microsoft` で、チャット、チャネルの新規投稿、返信に挿入できます。太字、リスト、リンク、表を保てます。

Google Chat（Gmail 内のパネルを含む）が保てるのは、太字、斜体、取り消し線、コード、リスト、リンクです。表はプレーンテキストになり、1 行が 1 行、セルはタブ区切りです。Chat の定型文は保存前にプレビューを見てください。

### バックアップと Google ドライブ

「すべてエクスポート」は `fluxsnip-backup-YYYYMMDD-HHmm.json` を書き出します。設定も入ります。1 つのサービスだけを書き出すと、ファイル名にその名前が入り、設定は入りません。

**統合**は、同じ id なら新しい方を残し、無いものは追加します。**置換**は、いまの内容を先にバックアップとしてダウンロードしてから、ファイルにあるサービスを入れ替えます。このブラウザのショートカットや言語を残すときは「拡張機能の設定も取り込む」を外します。

別のパソコンへ渡すときは、JSON をパソコン版 Google ドライブのフォルダに置き、同期を待ってから、そちらで読み込みます。自動では同期しません。

## プライバシー

- 定型文と設定は `chrome.storage.local` に残ります。
- `https:` で始まる画像は、メッセージを表示するときにそのアドレスから読み込まれます。
- 「Gemini プロンプト展開時に自動で作成を実行する」をオンにすると、Gemini 欄で展開したときに、その指示が追加のクリックなしで Google に送られます。

## 制限事項

- Gmail、Teams、Chat は予告なく画面を変えます。変わると、FluxSnip を更新するまで挿入できなくなることがあります。
- Google Chat は表を保てません。タブ区切りのテキストとして入ります。
- `{{cursor}}` は Gmail の本文と Gemini 指示でカーソルを置きます。Teams と Chat では無視されます。
- Gmail の宛先・件名・差出人は、Gmail の表示言語が日本語または英語のときだけ検出します。
- Gmail では、展開の直後の Ctrl+Z でキーワードに戻り、Ctrl+Y でやり直せます。Gmail が `insertHTML` を受け付けず DOM へ直接入れた場合は、直後の Ctrl+Z だけを処理します。Teams と Chat の元に戻す操作は、それぞれのエディタに従います。

## ヘルプ

各タブの「ヘルプ」から、そのタブの使い方が開きます。日本語と英語があり、OS のライトモード／ダークモードに従います。どの言語で開くかは、設定タブの表示言語に従います。

## 開発

```bash
npm install
npm run compile
npm test
npm run build
npm run dev
npm run zip
```

本物の Gmail に対する E2E は、専用のテスト用アカウントを使います。初回は `npm run e2e:login` でログインし、その後 `npm run e2e` を実行します。テストは `@example.com` のアドレスだけを使い、下書きを破棄します。メールは送信しません。`.e2e-profile/` にはそのログイン状態が入るので gitignore しています。
